Hull Door Logic

Set via POST /set · HULL DOOR · State: OPEN or CLOSED. Two side effects: may toggle the YACHT NAME hull-door light, and always calls syncLdDoorSpots.
flowchart TD A["POST /set · HULL DOOR"] --> B{State valid?} B -->|no| ERR["400 error"] B -->|yes| SAVE["setState: HULL DOOR = State"] SAVE --> BRANCH{State?} BRANCH -->|OPEN| OPCHK{"YACHT NAME\nlights.HULL DOOR == ON?"} OPCHK -->|yes| OPOFF["lights.HULL DOOR = OFF\nOSC → /t/name/aft/0"] OPCHK -->|no| OPSYNC["syncLdDoorSpots()"] OPOFF --> OPSYNC BRANCH -->|CLOSED| CLCHK{"YACHT NAME lights:\nUD SB == ON\nAND HULL DOOR != ON?"} CLCHK -->|yes| CLON["lights.HULL DOOR = ON\nOSC → /t/name/aft/1"] CLCHK -->|no| CLSYNC["syncLdDoorSpots()"] CLON --> CLSYNC

Two independent light groups: UD SB (underwater starboard side — always follows toggle) and HULL DOOR light (inner door surface — only ON when door is CLOSED).

LD Door Spots Logic

Spots on the inside surface of the hull door. ON only when door is OPEN and the LD Wet Area has any active state.

syncLdDoorSpots() is called whenever:

HULL DOOR → OPEN HULL DOOR → CLOSED POST /scene · LOWER DECK WET AREA POST /colour · LOWER DECK WET AREA POST /intensity · LOWER DECK WET AREA

If LD Door Spots appear stuck ON after the door closes, check the Current State panel above — if HULL DOOR still shows OPEN, the sensor hasn't sent the CLOSED update. Use the CLOSED button in the Set table to force it.
