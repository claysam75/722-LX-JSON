Scene state sync
A deck scene also updates the state of that deck's individual circuits, matching how Crestron tracks them: OFF turns them off, ON / DIM / NIGHT turn them on. ON / DIM / NIGHT never send OSC for the circuits, so the scene's programmed levels are kept.
Send OSC for circuits on OFF scenes
On an OFF scene, also send each linked circuit's OFF command so its ChamSys exec is released and matches the tracked state. When off, OFF scenes update state only.
Only applies while scene state sync is on.
